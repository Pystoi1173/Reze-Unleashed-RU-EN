# Unleashed RU/EN — предварительная версия 2026-11-18

Русско-английская модификация Unleashed для Flipper Zero. Основа: ветка dev DarkFlippers/unleashed-firmware, commit `53818b18`, API `88.28`. Перевод частичный; версия предназначена для предварительного тестирования.

## Изменения

- Русский по умолчанию, выбор English и сохранение настройки.
- Кириллица в стандартных шрифтах Canvas при обоих языках.
- Локализация подписей Launcher, System и ряда экранов основных приложений.
- Немедленное обновление всех 12 строк System при переключении языка и обновление подписей Launcher.
- Руководство: 12 тем по три страницы на каждом языке.
- Автоподсказки для встроенных приложений из главного меню; в этой конфигурации hook доступен только для Sub-GHz. Прямые запуски внешних FAP, файлов, Archive, ярлыков и RPC не перехватываются.
- Исправления UTF-8-переносов, обрезки и прокрутки строк.

## Установка

[Подробная установка и восстановление](INSTALL_RU.md) · [Что для чего: приложения и первые шаги](USER_GUIDE_RU.md)

1. Через qFlipper сохраните SD-карту и внутренние настройки.
2. Скачайте `flipper-z-f7-update-local.tgz` и сверьте SHA-256.
3. В qFlipper выберите **Install from file**, укажите TGZ и дождитесь завершения и повторного подключения.
4. Язык: `Настройки → Система → Язык`. Руководство: `Настройки → Руководство`.

Архив исходников GitHub не является пакетом обновления. Используйте указанный TGZ.

## Проверенный бинарный пакет

Сборка: `COMPACT=1 DEBUG=0 updater_package`, стандартная оптимизация `-Os`; дополнительно `-fmerge-all-constants` в `site_scons/cc.scons`. LTO не используется. В пакет входят firmware.dfu, updater.bin, radio.bin, resources.ths, splash.bin и update.fuf.

- SHA-256 TGZ: `db1df24088d41a4ad21a31eb0f33e0e118f7eddc64e00914a95578fd3fc598fa`.
- SHA-256 firmware.dfu: `5206f2fadad88a0c33f491cf19cea342359734aa2f9e4f23acdbe253257d40ff`.
- Адрес DFU-секции: `0x08000000`, длина 877780 байт, конец `0x080D64D4`.
- Граница C2: `0x080D7000`, запас 2860 байт. Проверка относится только к этому пакету.
- Radio firmware: `1.20.0`.

Бинарник собран из локально изменённых исходников до их фиксации в Git. Поэтому встроенный commit `53818b18` указывает на основу; точный бинарник определяется приведённым SHA-256. Пересборка после коммита может иметь другие метаданные и хеши.

## Фактические испытания

- Две установки через qFlipper; для исправленной версии получен `Full Update SUCCESS`.
- Загрузка, USB-подключение, RPC ScreenStream и ввод.
- Переключение RU/EN без исчезновения строк System и обновление Settings.
- English сохранился при обновлении, русский — после отдельной штатной перезагрузки.
- Все 12 английских тем по три страницы пройдены на первой сборке; все 12 русских тем — на исправленной.
- Archive, открытие существующего ИК-файла, стартовый экран внешнего NFC FAP.
- Sub-GHz после ручного просмотра руководства и перезагрузки запустился без повторного показа.

## Известные ограничения

- Перевод неполный; часть системных экранов, вкладки Archive и сторонние FAP остаются английскими. Пользовательские шрифты FAP могут не содержать кириллицы.
- Первый автоматический показ, отмена кнопкой Back и запуск приложения после автоматической подсказки аппаратно не проверены. Ручное прохождение отмечает первые девять тем просмотренными; UI сброса нет.
- Полная совместимость сторонних приложений, в том числе старых Momentum FAP, не подтверждена.
- Аппаратные протоколы и все режимы радио, NFC/RFID, iButton, GPIO, U2F и BadUSB не прошли полного регрессионного тестирования. Проверка интерфейса этого не заменяет.
- Отдельные пользовательские ярлыки и запуск приложения по RPC не проверены; просмотр экрана и ввод RPC проверены.
- В последней русской теме есть неудачный перенос слова «сомнении».
- В сборке остаётся предупреждение о совпадающем `.order=30` у System и Clock settings.
- Во время тестирования qFlipper иногда закрывался; устройство после повторного подключения оставалось доступным, причина отдельно не установлена.
