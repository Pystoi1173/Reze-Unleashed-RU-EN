# Reze Unleashed RU/EN v0.2.0-beta.1

Первый релиз под названием **Reze Unleashed RU/EN**. Сцены Резе, русский и английский интерфейс, встроенная справка и переведённые экраны приложений входят в один пакет для Flipper Zero.

## Что изменилось

- Добавлены 12 сцен на рабочем столе. В исходниках 203 уникальных кадра и 356 позиций в последовательностях воспроизведения. При наличии подходящих сцен Резе выбор ограничивается этим набором. Общие ограничения в манифесте и вес `255` дают каждой из 12 сцен одинаковый шанс. Перед применением остатка от деления отбрасывается неполный диапазон случайных чисел.
- При переключении языка экран «Система» обновляет строки на месте. Служба локали оповещает Loader, который обновляет подписи в своём потоке. Позиция выбора и идентификаторы, по которым запускаются и закрепляются приложения, сохраняются.
- Заголовки вкладок файлового браузера переводятся при отрисовке. Короткие подписи «Суб-ГГц», «Избр.» и «Обзор» рассчитаны на узкую рамку. Названия форматов и имя файла отображаются отдельно от заголовка.
- В сборку входят 12 тем «Справки» по три страницы на каждом языке, стандартные шрифты с кириллицей и частичный перевод экранов основных приложений. Подробнее в [руководстве пользователя](USER_GUIDE_RU.md).

## Пакет

| Параметр | Значение |
| --- | --- |
| Архив | `flipper-z-f7-update-reze-unleashed-ru-en.tgz` |
| SHA-256 архива | `c287cbf9011d4117c3a410f6f58972ce99ec5e45ba6fc4967a0b0f64e25f47b0` |
| SHA-256 `firmware.dfu` | `751a4f9878b4b3fd8161258f41ab781a4e3ff8e435a45e6ef8cd439c35769ebf` |
| Платформа и API | Flipper Zero F7, API `88.28` |
| Радиостек на тестовом устройстве | BLE Light `1.20.0` |
| Размер образа во флеш-памяти | `880092` байта |
| Конец образа, без включения конечного адреса | `0x080D6DDC` |
| Запас до границы BLE Light `0x080D7000` | `548` байт |

TGZ содержит четыре файла из установленного пакета `f7-update-reze-ru-archive` без изменений их содержимого. Пакет заменяет прошивку и ресурсы, сохраняя установленный радиостек и option bytes. Бинарник собран до публикационного коммита, поэтому на устройстве указаны ветка сборки `reze-ru` и базовый коммит `53818b18`. Для идентификации конкретного бинарника используйте хеш выше.

## Проверено на Flipper Zero

- Для пакета проверены цель F7, CRC, векторы запуска, двоичный образ, загрузчик и наличие ресурсов 12 сцен и 10 проверенных FAP.
- Последний образ установлен через USB CLI. После перезагрузки проверены подключение, версия API, радиостек и все 12 записей сцен на microSD. На экране архива подтверждён заголовок «Суб-ГГц».
- В сборке `f7-update-reze-ru-menu` с тем же исправлением меню проверены русский ↔ English, обновление открытого экрана «Система», возврат в оба меню, сохранение позиции и запуск «Справки» и «Часов». На более ранних сборках также проверялись стартовые экраны NFC и ИК-порта.

Релиз предварительный. Перевод экранов и сторонних FAP частичный. Полный прогон аппаратных режимов, первый автоматический показ справки и установка этого TGZ через qFlipper ещё требуют проверки. При открытии ИК-порта в ходе проверки по USB RPC устройство один раз перезапустилось с сообщением `out of memory`. После перезапуска ИК-порт открылся через USB CLI, и его русское меню удалось снять по RPC. Причина сбоя остаётся неизвестной. Проверенный способ установки и восстановление описаны в [инструкции](INSTALL_RU.md).

## English summary

This prerelease includes 12 Reze desktop animations, Russian and English menus, translated file browser tabs, and a bilingual User Guide. The packaged firmware and resources were installed on a Flipper Zero over USB CLI. The package retains the installed radio stack. Localization is partial and hardware testing was limited to the scenarios listed above.
