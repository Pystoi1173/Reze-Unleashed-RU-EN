# План проверки русской версии

Статус на 18 ноября 2026: вторая сборка собрана и установлена через qFlipper (`Full Update SUCCESS`). На первой сборке проверены загрузка, System на русском и английском и все 12 английских тем User Guide по три страницы.

На второй сборке подтверждены:

- Сохранение English после перезагрузки при обновлении; немедленное обновление строк System при RU → EN → RU и обновление подписей Settings в Launcher.
- Все 12 русских тем User Guide по три страницы.
- Русский System после отдельной штатной перезагрузки через Power.
- Открытие Archive кнопкой Down с рабочего стола и прямой запуск существующего сохранённого ИК-файла действием Run: без руководства, экран пульта виден, передача не выполнялась.
- Запуск внешнего NFC FAP до русского стартового меню без подсказки; Sub-GHz после ручного просмотра и перезагрузки запустился без повторного показа.

Автопоказ с отменой и завершением не проверен: после ручного прохождения все девять сопоставленных тем отмечены просмотренными, а сброса отметок через UI нет. Фактические результаты и ограничения приведены в [RELEASE_NOTES_RU.md](RELEASE_NOTES_RU.md); остальные пункты ниже являются планом и не считаются автоматически пройденными.

## Перед установкой

- Создать резервную копию SD-карты и настроек.
- В полной Git-копии с подмодулями выполнить `./fbt.cmd COMPACT=1 DEBUG=0 updater_package`.
- Устранить ошибки сборки и экспорта API до установки.
- Устанавливать только успешно собранный пакет штатным способом.

## Язык и отрисовка

- Проверить русский язык при отсутствии настроек локали.
- Переключить на English, выйти из настроек и снова открыть приложения.
- Перезагрузить устройство и проверить сохранение языка.
- Повторить для русского языка; отдельно проверить Ё/ё и Й/й.
- Проверить заголовки, три нижние кнопки одновременно, длинные имена файлов и многострочные сообщения.
- Проверить пустой текст, узкие поля и длинные слова: нет зависания и разрезанных UTF-8-символов.
- В System проверить немедленное обновление всех 12 строк при смене языка; после возврата проверить обновление подписей Settings и главного меню. Остальные экраны повторно открыть.
- При English проверить отображение кириллицы в именах файлов; отдельно проверить обрезку по ширине и прокрутку длинных русских строк.

## Автоматические подсказки

По исходникам и таблице приложений текущей сборки автопоказ действует только для Sub-GHz из главного меню. NFC, RFID, iButton, Infrared, GPIO, Bad USB и U2F собраны как внешние FAP и должны запускаться без автоподсказки; их руководство проверяется вручную. Archive имеет тему в таблице, но отдельный путь открытия Archive не перехватывается. Дополнительные темы BT Remote, настройки и безопасность доступны только вручную.

Сценарии ниже не пройдены. Для положительных сценариев нужен непросмотренный Sub-GHz в отдельном тестовом состоянии; на текущем устройстве он уже отмечен просмотренным. Не менять данные устройства вручную и не выполнять Factory Reset ради этого теста.

- При включённом автопоказе выбрать Sub-GHz из главного меню.
- Сначала нажать Back на первой странице, затем при повторном запуске на промежуточной: запуск приложения отменён, тема остаётся непросмотренной.
- Затем пройти все страницы через «Далее»/«Готово»: запускается именно Sub-GHz.
- Закрыть приложение и открыть повторно: подсказка больше не появляется.
- Проверить сохранение отметки после перезагрузки.
- В отдельном исходном состоянии завершить непросмотренную тему Sub-GHz вручную в User Guide: последующий запуск из главного меню не показывает её повторно. Не совмещать этот сценарий с первым завершением автоподсказки в одном состоянии.
- В отдельном исходном состоянии отключить автопоказ при непросмотренной теме, перезагрузить устройство: Sub-GHz запускается без подсказки.
- Включить автопоказ снова: непросмотренная тема снова допускает автопоказ, просмотренная остаётся просмотренной. Проверка только на просмотренной теме не доказывает действие переключателя.

## Неизменённые пути запуска

- Открыть файл из Archive, проверить открытие в соответствующем приложении без автоподсказки.
- Проверить ярлык рабочего стола, внешнее FAP и системные настройки.
- Проверить запуск через RPC штатным клиентом: нет подсказки и зависания.
- Проверить существующие короткие и долгие нажатия внутри приложений.

## Настройки и ошибки

- В «Настройки → Руководство → Подсказки запуска» проверить левую кнопку «Выкл», правую «Вкл» и Back без изменений. Выключение и повторное включение не очищают отметки первых девяти тем; отдельного сброса через UI нет.
- В изолированном тестовом состоянии проверить отсутствие файла настроек подсказок: включённый автопоказ по умолчанию.
- В отдельной тестовой копии проверить повреждённые настройки: безопасные значения по умолчанию.
- В изолированном тестовом состоянии проверить невозможность сохранения: нет падения; после перезапуска возможен повторный показ темы. Не изменять данные основного устройства вручную для этих проверок.
- Проверить 12-часовой формат в 00:00, 11:59, 12:00, 12:59 и 23:59.

## Безопасность испытаний

Проверять интерфейс только на своих тестовых устройствах. Не записывать данные на важные карты/ключи, не передавать радиосигналы без разрешения и не запускать BadUSB на чужом компьютере. Для GPIO соблюдать допустимые напряжения.

## Фиксация результатов

Для каждого случая записать версию основы, параметры сборки, язык, ожидаемый и фактический результат. При обрезке текста приложить фотографию экрана. Успех статического скрипта не заменяет эти испытания.
