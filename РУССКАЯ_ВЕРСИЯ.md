# Reze Unleashed RU/EN — устройство прошивки

## Локализация

- Служба `locale` хранит выбранный язык во внутренней памяти. Системные строки меняются в текущей модели списка. Loader получает уведомление и обновляет подписи меню в своём потоке. Английские идентификаторы запуска и закрепления сохраняются.
- Предусмотрена кириллица в стандартных шрифтах. Общие функции отрисовки учитывают границы символов UTF-8 при переносе, обрезке и прокрутке. Приложения с собственными шрифтами требуют отдельной проверки.
- Вкладки файлового браузера используют `locale_translate()` при отрисовке. Ширина рамки составляет 51 пиксель. Русские подписи скомпонованы под эту ширину, а имена файлов выводятся отдельно.
- Справка доступна из настроек. В таблице `guide_topics` файла `applications/settings/user_guide/user_guide.c` находятся 12 двуязычных тем. Автопоказ предусмотрен для встроенного Sub-GHz при запуске через главное меню. Обычный запуск FAP, открытие файлов, ярлыки, RPC и отдельный вход в архив используют штатные маршруты.

## Ресурсы рабочего стола

Сцены лежат в `assets/dolphin/external/L1_Reze_*`. PNG-кадры имеют размер 128×64. Для каждой сцены `meta.txt` задаёт порядок кадров, длительность и число кадров в пассивной и активной части. Общий `manifest.txt` задаёт условия доступности и вес. Выбор выполняет `animation_manager.c` после фильтрации подходящих сцен.

## Сборка на Windows

Клонируйте репозиторий с `--recurse-submodules` в короткий путь без пробелов. FBT может загрузить инструменты при первом вызове. Для компоновки компактной прошивки нужен плагин LTO из поставки GCC. Проверьте актуальный путь к `liblto_plugin.dll`, прежде чем запускать сборку.

```powershell
$env:FBT_LTO_PLUGIN = (Resolve-Path '.\toolchain\x86_64-windows\libexec\gcc\arm-none-eabi\12.3.1\liblto_plugin.dll').Path
.\fbt.cmd --proxy-env=FBT_LTO_PLUGIN DEBUG=0 COMPACT=1 build/f7-firmware-C/firmware.dfu build/f7-updater-C/updater.bin resources
```

Для пакета по образцу релиза используйте Python из toolchain и `scripts/update.py generate -t f7`. Передайте каталог назначения через `-d`, версию через `-v`, `firmware.dfu` через `--dfu`, `updater.bin` через `--stage` и каталог `build/f7-firmware-C/resources` через `-r`. Используйте параметры пакета без записи радиостека и option bytes. Перед установкой убедитесь, что адрес загрузки и конец образа укладываются в доступный диапазон флеш-памяти устройства. Параметры последней проверенной сборки приведены в [заметках релиза](RELEASE_NOTES_RU.md).

Для проверки UTF-8, зависимостей локали и экспортов API в Windows используйте `scripts/check_russian_prototype.ps1`. Проверки на устройстве описаны в [плане испытаний](RU_TEST_PLAN.md).
