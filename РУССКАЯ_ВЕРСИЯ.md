# Русская версия Unleashed — рабочий прототип

Это не официальный релиз Unleashed и не Momentum. Основа: ветка `dev` DarkFlippers/unleashed-firmware, скачанная 18 ноября 2026 года.

## Цель

Русский и английский интерфейс, кириллица, справка по базовым приложениям. Полный перевод всех экранов и сторонних приложений ещё не выполнен. Подтверждённые результаты сборки, установки и ограниченной аппаратной проверки приведены ниже; они не означают проверки всех функций прошивки.

## Текущее состояние

- Добавлены выбор языка и сохранение настройки; русский используется по умолчанию.
- Для стандартных шрифтов Canvas (`FontPrimary`, `FontSecondary`, `FontKeyboard`) добавлена кириллица независимо от выбранного языка, в том числе для русских имён файлов в English. Пользовательские шрифты приложений этим не покрываются.
- Переведены системные настройки, стартовые меню шести базовых приложений и несколько сообщений сохранения/ошибок.
- Добавлено ручное руководство `Настройки → Руководство` (`Settings → User Guide`): 12 тем по три страницы и пункт «Подсказки запуска».
- Сохраняются включение автопоказа и отметки первых девяти тем. По исходникам текущей сборки автопоказ действует только для Sub-GHz из главного меню: NFC, RFID, iButton, Infrared, GPIO, Bad USB и U2F собраны как внешние FAP, а их путь запуска не перехватывается. Archive имеет отдельный путь запуска; он, RPC, ярлыки и открытие файлов также не перехватываются. Темы «Настройки», «BT Remote» и «Важно» доступны только вручную.
- В «Подсказки запуска» левая кнопка «Выкл» отключает автопоказ, правая «Вкл» включает; Back выходит без изменения настройки. Переключение не очищает просмотренные темы; отдельного сброса отметок через UI нет.
- Добавлен перевод отображаемых подписей главного меню и списка настроек без изменения идентификаторов запуска. В System все 12 строк обновляются при переключении языка; меню Loader также обновляет подписи после смены языка.
- Исправлены UTF-8-границы и гарантированное продвижение в `elements_multiline_text_aligned`, а также обрезка по ширине и прокрутка строк в общих функциях `elements`; увеличены буферы для русских строк в экранах RFID/NFC/Archive, включая словарную атаку NFC. Другие обработчики текста ещё требуют отдельной проверки.
- Дополнительно переведены экраны подтверждения выхода/сохранения/повторного чтения и обнаружения NFC, меню дополнительных действий NFC и экран словарной атаки, несохранённые данные Sub-GHz, чтение RFID, меню сохранённых RFID/iButton, повтор ИК-записи, универсальные пульты и управление отправкой, USB-UART и GPIO-тест, удаление сопряжения и состояния BadUSB, создание папки и информация Archive, экран U2F. Переведены настройки виброотклика. Покрытие базовых приложений остаётся частичным.
- Полный перевод, стили главного меню и сторонние FAP ещё требуют доработки. Границы и сценарий автопоказа описаны в `applications/services/loader/GUIDE_INTEGRATION.md`.
- Скрипт `scripts/check_russian_prototype.ps1` проверяет UTF-8, наличие файлов, экспортов API, ключевых участков автопоказа и совпадение форматных спецификаторов в переводах. Он НЕ компилирует код.
- Для сервисов, настроек и базовых приложений с локализацией добавлены явные зависимости `locale` в `application.fam`, включая Clock. Переведённая строка не должна передаваться напрямую как формат `snprintf`; при добавлении таких экранов используйте фиксированный формат и `%s` либо ограниченное копирование.
- Добавлен подробный план ручного тестирования `RU_TEST_PLAN.md`: язык, UTF-8-переносы, автоподсказки, неизменённые пути запуска, настройки и безопасность.

## Сборки и подтверждённые испытания

Исходники находятся в полной Git-копии с подмодулями; инструменты FBT установлены. После резервирования SD и внутреннего хранилища первая и вторая сборки собраны и установлены через qFlipper; для второй установки подтверждён `Full Update SUCCESS`.

- На первой сборке подтверждены загрузка, экран и ввод RPC, русский System, переключение English и все 12 английских тем User Guide по три страницы.
- На второй сборке English сохранился после перезагрузки при обновлении. Проверены немедленное обновление строк System при RU → EN → RU и обновление подписей Settings в Launcher.
- Пройдены все 12 русских тем по три страницы.
- После отдельной штатной перезагрузки через Power подтверждён русский System.
- Archive открыт кнопкой Down с рабочего стола; существующий сохранённый ИК-файл запущен действием Run напрямую, без руководства. Экран пульта виден; передача не выполнялась.
- Внешний NFC FAP запустился до русского стартового меню без подсказки. Sub-GHz после ручного просмотра темы и перезагрузки открылся без повторного показа.

Автопоказ с отменой и завершением не проверен: после ручного прохождения все девять сопоставленных тем отмечены просмотренными, а сброса отметок через UI нет. Подробные подтверждённые результаты и ограничения приведены в [RELEASE_NOTES_RU.md](RELEASE_NOTES_RU.md). Полная совместимость пользовательских FAP и аппаратных функций ещё не подтверждена.

## Сборка на Windows

1. Установите Git for Windows с официального сайта https://git-scm.com/ .
2. Клонируйте этот репозиторий рекурсивно (`--recursive`) в отдельную папку, лучше с коротким латинским путём.
3. Убедитесь, что подмодули загружены: из корня копии выполните `git submodule update --init --recursive`. Изменения прототипа уже входят в этот репозиторий; отдельная копия upstream Unleashed их не содержит. Не заменяйте `.git` и не удаляйте подмодули. При переносе изменений на другую версию основы сначала сопоставьте версии: автоматическое копирование поверх другой версии может сломать сборку.
4. Запустите из корня полной копии:

```powershell
.\fbt.cmd COMPACT=1 DEBUG=0 updater_package
```

FBT скачивает собственные инструменты сборки. При изменении экспортируемого API может потребоваться обновление SDK/API по указаниям FBT. Ошибки сборки нужно устранить до установки.

## Перед испытанием на устройстве

- Сделайте резервную копию SD-карты и настроек через qFlipper.
- Используйте исправную SD-карту и заряженный Flipper Zero.
- Устанавливайте только успешно собранный пакет штатным способом; следуйте документации qFlipper/Unleashed.
- Проверьте русские буквы, переносы строк, выход кнопкой «Назад», смену языка, сохранение настроек и справку.
- Не меняйте назначения долгих нажатий без проверки: приложения уже могут их использовать.
- Не выполняйте запись на важные карты и ключи при тестировании интерфейса.
- Используйте радио, NFC/RFID, iButton и USB только со своими устройствами или с разрешения владельца.
