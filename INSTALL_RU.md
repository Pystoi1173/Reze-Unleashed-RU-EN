# Установка Reze Unleashed RU/EN

Подготовьте Flipper Zero, исправную microSD и USB-кабель с передачей данных. Пакет проверен на устройстве с **BLE Light 1.20.0**. Пакет сохраняет установленный радиостек. Если у вас другой вариант стека, перед установкой нужно проверить доступную границу флеш-памяти. [Параметры проверенного пакета](RELEASE_NOTES_RU.md#пакет)

## Подготовка

1. Зарядите Flipper Zero и подключите его к компьютеру.
2. Сохраните внутренние данные и настройки через **qFlipper → Advanced controls → Backup**. Отдельно скопируйте microSD через файловый менеджер qFlipper или кардридер. Запишите версию текущей прошивки для возврата.
3. Скачайте `flipper-z-f7-update-reze-unleashed-ru-en.tgz` и `SHA256SUMS.txt` из **Assets**. Для установки используйте TGZ, а архивы **Source code** предназначены для работы с исходниками. [Скачать релиз](https://github.com/Pystoi1173/Reze-Unleashed-RU-EN/releases/tag/reze-v0.2.0-beta.1)
4. Сверьте SHA-256 архива с опубликованным значением. Если хеш отличается, скачайте архив заново.

В PowerShell вычислите хеш так:

```powershell
Get-FileHash .\flipper-z-f7-update-reze-unleashed-ru-en.tgz -Algorithm SHA256
```

На macOS используйте `shasum -a 256`, на Linux — `sha256sum`.

## Через qFlipper

1. В qFlipper откройте **Advanced controls → Install from file** и выберите скачанный TGZ целиком.
2. Дождитесь завершения обновления и повторного подключения. Оставьте кабель и microSD на месте, пока идёт установка. [Документация qFlipper](https://docs.flipper.net/zero/qflipper)

TGZ упакован в формате FBT. На устройстве содержимое этого пакета было проверено при установке по USB CLI.

## Через USB CLI

Распакуйте TGZ и найдите вложенную папку `f7-update-reze-unleashed`. Закройте qFlipper и другие программы, открывшие USB-порт Flipper. Выйдите из открытых приложений на рабочий стол. Из клона проекта с подготовленным Python-окружением FBT запустите команду. Подставьте действительный порт и путь к распакованному файлу.

```powershell
python scripts/selfupdate.py --port COM4 --pkg_dir_name f7-update-reze-unleashed path/to/f7-update-reze-unleashed/update.fuf
```

Утилита загрузит папку на microSD и передаст команду обновления. Дождитесь появления рабочего стола и возврата USB-порта.

## После загрузки

- Выберите язык в **Настройки → Система → Язык** / **Settings → System → Language**. При чистых настройках используется русский. Ранее сохранённый язык может сохраниться при обновлении.
- Откройте **Настройки → Справка** / **Settings → User Guide**. Откройте тему и листайте её кнопкой **Далее**.
- С рабочего стола откройте файловый браузер кнопкой **Вниз** в стандартной раскладке. Перейдите на вкладку «Суб-ГГц».
- Вернитесь на рабочий стол и проверьте, что Flipper показывает сцены Резе. Выбор зависит от текущих условий показа анимаций.

## Восстановление

Если Flipper пропал из qFlipper, дождитесь конца перезагрузки, проверьте кабель и закройте программы, которые могут занимать USB-порт. Если прошивка не загружается, воспользуйтесь штатным восстановлением через qFlipper. Восстановление может вернуть официальную прошивку. [Официальная инструкция](https://docs.flipper.net/zero/basics/firmware-update/firmware-recovery)
