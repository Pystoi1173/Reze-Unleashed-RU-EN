# Установка Unleashed RU/EN через qFlipper

Руководство для владельцев Flipper Zero, которым нужен русский интерфейс с возможностью вернуться на English. Версия предварительная: перевод частичный, полная совместимость всех приложений и аппаратных режимов ещё не подтверждена.

[Что умеют приложения и для чего они нужны](USER_GUIDE_RU.md) · [Изменения и ограничения релиза](RELEASE_NOTES_RU.md) · [Результаты испытаний](RU_TEST_PLAN.md)

## 1. Подготовьте устройство и компьютер

Понадобятся Flipper Zero, исправная microSD-карта в устройстве, USB-кабель с передачей данных и компьютер с Windows, macOS или Linux. Зарядите Flipper перед установкой.

Установите **qFlipper** с [официального сайта Flipper Zero](https://flipperzero.one/update). Это программа для установки прошивки по USB, резервирования настроек и работы с файлами. [Официальное руководство qFlipper](https://docs.flipper.net/zero/qflipper) поможет найти вкладки, если интерфейс вашей версии отличается.

Подключите Flipper кабелем, откройте qFlipper и дождитесь появления информации об устройстве. Закройте другие программы, использующие USB-соединение с Flipper.

## 2. Сохраните данные до установки

Сделайте **две отдельные копии**. Резервная копия внутреннего хранилища не заменяет копию SD-карты.

| Что сохранить | Зачем | Как |
| --- | --- | --- |
| Внутренние данные и настройки | Чтобы иметь возможность восстановить настройки и служебные данные | В qFlipper откройте **Advanced controls → Backup** и сохраните файл на компьютер. Дождитесь успешного завершения |
| Всё содержимое microSD | На карте лежат ваши сохранённые сигналы, пульты, метки, скрипты и приложения | В **File manager** скачайте папки и файлы SD-карты на компьютер. Для выделенных элементов обычно доступны контекстное меню Download и Ctrl+D; на macOS — Command+D |
| Версию прежней прошивки | Чтобы подобрать пакет для возврата | Запишите название и версию из qFlipper; если сохранился её установочный пакет, положите его рядом с копией |

Проверьте, что резервные файлы действительно появились на компьютере и копирование завершилось без ошибок. Храните копии вне папки устройства. Если пользуетесь U2F, заранее убедитесь, что у аккаунтов есть другой способ входа и резервные коды.

Во время установки не выбирайте **Factory Reset**, **Erase** или форматирование SD. Обновление рассчитано на сохранение данных, но резервная копия нужна на случай сбоя и различий между прошивками.

## 3. Скачайте правильный файл

На странице этого GitHub-репозитория откройте **Releases**, затем нужный предварительный релиз и блок **Assets**. Прочитайте ограничения именно выбранного релиза.

Скачайте **`flipper-z-f7-update-local.tgz`**. Это готовый пакет для qFlipper; распаковывать его не нужно.

| Файл или раздел | Для чего нужен |
| --- | --- |
| `flipper-z-f7-update-local.tgz` | Установка этой версии через **Install from file** |
| `Source code (zip)` / `Source code (tar.gz)` | Исходники для разработки; эти архивы не устанавливаются как прошивка |
| `SHA256SUMS.txt`, если приложен | Проверка целостности скачанного TGZ |
| `INSTALL_RU.md` | Эта инструкция |
| `USER_GUIDE_RU.md` | Объяснение приложений, управления и первых шагов |
| `RELEASE_NOTES_RU.md` | Изменения, проверенная версия пакета и известные ограничения |

Для первого проверенного пакета от 18 ноября 2026 года SHA-256:

```text
db1df24088d41a4ad21a31eb0f33e0e118f7eddc64e00914a95578fd3fc598fa
```

Проверить в Windows PowerShell, открытом в папке загрузки:

```powershell
Get-FileHash .\flipper-z-f7-update-local.tgz -Algorithm SHA256
```

На macOS:

```sh
shasum -a 256 flipper-z-f7-update-local.tgz
```

На Linux:

```sh
sha256sum flipper-z-f7-update-local.tgz
```

Регистр букв в хеше не важен. Если значение отличается от опубликованного для выбранного релиза, заново скачайте файл и проверьте его до установки. У более новых релизов будет свой хеш.

## 4. Установите пакет

1. Убедитесь, что резервирование завершено, microSD вставлена, а qFlipper видит устройство.
2. Откройте вкладку **Advanced controls**.
3. Нажмите **Install from file** и выберите скачанный `flipper-z-f7-update-local.tgz`.
4. Подтвердите установку и дождитесь её окончания. Во время записи не отключайте кабель, не извлекайте SD-карту и не закрывайте qFlipper. Flipper может перезагрузиться и временно исчезнуть из списка устройств.
5. Дождитесь сообщения об успешной установке и повторного подключения. На устройстве должен появиться рабочий стол.

Для RU/EN используйте локальный TGZ через **Install from file**. Обычная кнопка **Update** с каналом Release/RC/Dev устанавливает прошивку выбранного канала qFlipper и может заменить RU/EN официальной версией.

## 5. Проверьте результат

1. Откройте **Настройки → Система → Язык**. В английском интерфейсе это **Settings → System → Language**. Выберите **Русский** или **English** кнопками влево/вправо на строке языка.
2. Вернитесь в меню. Названия настроек должны обновиться. Если раньше уже выбирали English, сохранённый выбор может остаться после обновления.
3. Откройте **Настройки → Руководство** / **Settings → User Guide**. Выберите тему и пролистайте её: справа **Далее**, на последней странице **Готово**. **Назад** закрывает тему.
4. Откройте **Архив / Archive** и убедитесь, что сохранённые файлы на SD доступны. Для проверки достаточно просмотра списка и открытия знакомого файла.
5. После завершения обновления выполните обычную перезагрузку через меню питания и проверьте, что язык сохранился.

На устройстве автора эти действия, установка через qFlipper и все 12 тем встроенного руководства были проверены. Это ограниченная проверка интерфейса; полный перечень результатов находится в [заметках релиза](RELEASE_NOTES_RU.md).

## Если возникла проблема

| Проблема | Что проверить |
| --- | --- |
| qFlipper не видит Flipper | USB-кабель должен передавать данные. Попробуйте другой порт, закройте программы, занявшие соединение, затем переподключите устройство. На Windows см. [официальную помощь по драйверам](https://docs.flipper.net/zero/qflipper/windows-debug) |
| qFlipper не принимает архив | Выбран именно TGZ из Assets, а не исходный ZIP; файл полностью скачан, SHA-256 совпадает |
| Ошибка SD или ресурсов | Убедитесь, что microSD распознаётся и на ней есть свободное место. Сначала сохраните доступные файлы; не начинайте с форматирования |
| Обновление оборвалось | Откройте **LOGS → OPEN FULL LOG**, сохраните журнал и найдите первую ошибку. Когда qFlipper вновь увидит устройство, повторите установку того же проверенного TGZ |
| Устройство не загружается после сбоя | Используйте [официальное восстановление прошивки через qFlipper](https://docs.flipper.net/zero/basics/firmware-update/firmware-recovery). Восстановление может заменить RU/EN официальной прошивкой; личные копии понадобятся для возврата данных |
| Остались английские пункты | Перевод пока частичный. Некоторые экраны и сторонние приложения ещё не переведены |
| Внешнее приложение сообщает об ошибке API | Нужна версия FAP для совместимой прошивки/API. Старые приложения Momentum могут не подойти; сохраните их копии перед заменой |
| Руководство не появляется автоматически | Откройте его вручную в Settings. Автопоказ предусмотрен только для встроенного Sub-GHz из главного меню и ещё не проверен на первом запуске. Просмотренные темы повторно не показываются |

Если qFlipper закрылся, сначала снова откройте его и проверьте состояние устройства и журнал. Если Flipper продолжает установку, дайте ей закончиться.

## Как вернуться на прежнюю прошивку

Через qFlipper установите сохранённый совместимый пакет прежней прошивки с помощью **Install from file**. Для возврата к официальной версии используйте официальный канал **Release** в qFlipper. Затем проверьте устройство и файлы.

При необходимости восстановите внутреннюю резервную копию через **Advanced controls → Restore**, учитывая совместимость с той прошивкой, на которой она создана. Пользовательские файлы верните из отдельной копии microSD. Не перезаписывайте всю карту старыми приложениями и ресурсами поверх другой версии без необходимости.

## Как сообщить об ошибке

Создайте Issue в этом RU/EN-репозитории и укажите версию релиза, язык, приложение, точные действия и ожидаемый результат. Приложите снимок экрана и нужный фрагмент журнала qFlipper. Перед публикацией уберите личные данные, идентификаторы, содержимое карт и ключей. Полные резервные копии устройства публиковать не нужно.
