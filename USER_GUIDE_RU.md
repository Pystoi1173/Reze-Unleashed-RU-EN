# Unleashed RU/EN: что для чего и с чего начать

Эта прошивка добавляет русский интерфейс, выбор English, кириллицу в стандартных шрифтах и встроенное руководство к Unleashed для Flipper Zero. Это предварительная версия с частичным переводом. Основные приложения унаследованы от Unleashed; их наличие не означает, что каждый режим проверен в этой RU/EN-сборке.

**Первый раз здесь?** Начните с [установки через qFlipper](INSTALL_RU.md), затем выберите язык и откройте руководство на устройстве. [Заметки релиза](RELEASE_NOTES_RU.md) содержат точные результаты испытаний и ограничения.

## Что изменено в RU/EN

| Изменение | Что это даёт |
| --- | --- |
| Русский по умолчанию | На новом состоянии настроек система начинает с русского. Ранее сохранённый English сохраняется |
| Выбор English | Можно сменить язык в **Настройки → Система → Язык**; выбор сохраняется после перезагрузки |
| Кириллица в стандартных шрифтах | Русские подписи и имена файлов отображаются и при English. Собственные шрифты сторонних приложений могут не поддерживать кириллицу |
| Перевод меню и части экранов | Переведены подписи Launcher, System и ряд экранов основных приложений; покрытие пока неполное |
| Встроенное руководство | В **Настройки → Руководство** доступны 12 тем, каждая по три страницы на русском и английском |
| Исправления обработки UTF-8 | Общие функции переноса, обрезки и прокрутки учитывают границы символов. Остальные обработчики текста требуют отдельных проверок |

Прошивка сохраняет идентификаторы запуска приложений; язык меняет отображаемые подписи. Совместимость всех сторонних FAP, в том числе старых приложений Momentum, ещё не подтверждена.

## Базовое управление

| Кнопка | Обычное действие |
| --- | --- |
| Вверх / вниз | Выбор пункта или переход по списку |
| Короткое OK | Открыть пункт, выбрать действие, подтвердить |
| Влево / вправо | Сменить значение в строке настройки или выполнить действие, подписанное внизу экрана |
| Назад / Back | Вернуться на предыдущий экран или отменить действие |

Смотрите на подписи внизу текущего экрана: отдельные приложения назначают кнопки по-своему. В штатной раскладке этой проверенной сборки кнопка вниз на рабочем столе открывает Archive. Пользовательские ярлыки могут отличаться.

Для обычного выбора пунктов достаточно коротких нажатий. Долгие нажатия зависят от приложения и настроек.

## Язык и встроенные подсказки

Чтобы выбрать язык, откройте **Настройки → Система → Язык** или **Settings → System → Language** и смените значение кнопками влево/вправо. После возврата в меню подписи настроек должны обновиться.

Чтобы открыть справку, перейдите в **Настройки → Руководство** / **Settings → User Guide**, выберите тему и нажимайте правую кнопку **Далее / Next**. На третьей странице она станет **Готово / Done**. **Назад** закрывает тему.

Внизу списка есть **Подсказки запуска / First-launch guides**. Левая кнопка **Выкл / Off** отключает автопоказ, правая **Вкл / On** включает его; Back выходит без изменения настройки.

В этой конфигурации автоматическая подсказка предусмотрена только для встроенного **Sub-GHz**, запускаемого из главного меню. Остальные основные приложения собраны как внешние FAP или имеют другой путь запуска. Archive, открытие файлов, ярлыки и RPC не перехватываются. Все темы можно открыть вручную.

Полный ручной просмотр первых девяти тем отмечает их просмотренными. Выключение и включение подсказок не очищает отметки; кнопки сброса в интерфейсе пока нет. Первый автоматический показ, отмена и последующий запуск приложения ещё не проверены на устройстве.

## Для чего нужны приложения

Примеры ниже относятся к вашим устройствам и тестовым меткам либо к оборудованию, которое владелец разрешил проверять. Это описание назначения, а не подтверждение полной аппаратной совместимости этой сборки.

| Раздел | Для чего нужен | Понятный первый сценарий | Что учитывать |
| --- | --- | --- | --- |
| **Sub-GHz** | Работа с поддерживаемыми радиосигналами ниже 1 ГГц | Изучить сигнал своего совместимого тестового пульта | Поддерживаются не все частоты и протоколы. Плавающий код не превращается в рабочую копию простым сохранением. Соблюдайте региональные ограничения передачи |
| **NFC** | Чтение поддерживаемых бесконтактных карт и меток 13,56 МГц, сохранение данных и доступные режимы эмуляции | Прочитать свою учебную NFC-метку и посмотреть определённый тип | Доступ к защищённым данным ограничен; чтение UID не равно копированию всей карты. Возможность записи зависит от метки и протокола |
| **RFID 125 кГц** | Работа с поддерживаемыми низкочастотными метками | Считать свою совместимую тестовую метку и сохранить запись | Это отдельная технология от NFC. Запись требует подходящей перезаписываемой метки |
| **iButton** | Работа с поддерживаемыми контактными ключами | Прочитать свой тестовый ключ, приложив его к контактам Flipper | Это не бесконтактная NFC-карта; режимы зависят от типа ключа |
| **Инфракрасный / Infrared** | Запоминание и отправка ИК-команд пультов | Сохранить одну кнопку своего телевизионного пульта | Bluetooth- и радиопульты не становятся ИК-пультами. Для отправки направьте ИК-порт на приёмник |
| **GPIO** | Подключение совместимых электронных модулей и отладочных интерфейсов | Посмотреть доступные режимы и распиновку перед подключением учебного модуля | Сверяйте напряжения и назначение контактов по документации; не подавайте произвольное питание |
| **BadUSB** | Выполнение подготовленного сценария ввода, когда Flipper работает как клавиатура | На своём тестовом компьютере напечатать строку в пустом текстовом редакторе | Скрипт может вводить команды. Перед запуском прочитайте его целиком и проверьте раскладку клавиатуры |
| **U2F** | Использование Flipper как второго фактора входа на совместимых сайтах | Зарегистрировать его в тестовом аккаунте с запасным способом входа | Сохраните резервные коды; не оставляйте экспериментальную прошивку единственным способом входа |
| **Архив / Archive** | Просмотр папок, сохранённых файлов и запуск поддерживаемых форматов | Найти ранее сохранённый ИК-пульт или запись метки | Удаление файла убирает сохранённые данные. Перед изменениями держите копию на компьютере |
| **BT Remote** | Управление совместимым устройством как Bluetooth-пультом | Подключиться к своему компьютеру для управления презентацией | Возможности зависят от приложения и устройства; проверяйте имя при сопряжении |
| **Настройки / Settings** | Язык, экран, звук, вибрация, связь и другие параметры | Выбрать язык, яркость и удобный формат времени | Часть пунктов остаётся английской. Сброс и форматирование влияют на данные |
| **Часы / Clock** | Просмотр времени и функции установленного приложения часов | Проверить время и формат отображения | Набор режимов зависит от версии приложения |

Тема **Важно / Safety** во встроенном руководстве напоминает об ограничениях оборудования, региона и работе с разрешёнными тестовыми устройствами.

## Первые шаги на знакомых примерах

### Открыть сохранённый файл

Откройте **Archive**, выберите знакомую папку, затем файл. Короткое **OK** открывает меню или поддерживаемый файл, **Back** возвращает назад. Для проверки после установки достаточно убедиться, что файл виден и открывается. Передача сигнала для такой проверки не нужна.

### Сохранить кнопку собственного ИК-пульта

1. Откройте **Infrared / Инфракрасный** и выберите обучение новой кнопке: пункт может называться **Learn** или **Learn New Remote**.
2. Направьте передатчик своего пульта на ИК-приёмник Flipper и нажмите нужную кнопку пульта.
3. Если команда распознана, сохраните её с понятным именем, например `TV_Power`.
4. Для проверки откройте сохранённый пульт, направьте Flipper на свой телевизор и выберите кнопку отправки.

Это пример использования приложения; запись и передача ИК-команд в рамках проверки этой RU/EN-версии не выполнялись. Если пульт использует Bluetooth или радиосвязь, ИК-обучение его не прочитает.

### Прочитать свою учебную NFC-метку

Откройте **NFC → Read / Чтение**, приложите метку к задней стороне Flipper и дождитесь результата. Посмотрите определённый тип и доступные сведения. Сохранение создаёт файл на SD-карте; оно само по себе не записывает данные в метку.

Если чтение не удалось, проверьте положение метки и поддержку её протокола. NFC и RFID 125 кГц запускаются из разных приложений. Аппаратное чтение NFC в этой RU/EN-сборке ещё не прошло полного тестирования.

## Что означают типичные действия

| Действие | Значение |
| --- | --- |
| **Read / Чтение** | Получить доступные данные от метки, ключа или сигнала |
| **Save / Сохранить** | Записать результат в файл на Flipper, обычно на microSD |
| **Emulate / Эмуляция** | Попытаться представить сохранённые данные совместимому считывателю; это не гарантирует работу как оригинал |
| **Send / Передача** | Передать сохранённую команду или сигнал поддерживаемым способом |
| **Write / Запись** | Записать данные на совместимый физический носитель, если этот режим доступен |
| **Run / Запустить** | Выполнить файл или открыть его соответствующим приложением; результат зависит от типа файла |

## Где лежат файлы и чем они отличаются

Типичные папки microSD показаны ниже. Конкретные приложения могут хранить данные в других местах; сохраняйте всю карту перед обновлением.

| Папка или расширение | Что обычно содержит |
| --- | --- |
| `subghz/`, `.sub` | Сохранённые радиосигналы Sub-GHz |
| `nfc/`, `.nfc` | Сохранённые данные NFC |
| `lfrfid/`, `.rfid` | Записи RFID 125 кГц |
| `ibutton/`, `.ibtn` | Записи контактных ключей |
| `infrared/`, `.ir` | Сохранённые ИК-пульты и кнопки |
| `badusb/`, `.txt` | Текстовые сценарии BadUSB |
| `apps/`, `.fap` | Внешние приложения Flipper; они зависят от совместимости API |
| `.tgz` из релиза | Установочный пакет прошивки для qFlipper |

Через **qFlipper → File manager** можно скачивать файлы на компьютер и загружать их обратно. При загрузке совпадающие имена могут быть перезаписаны — сначала сохраните копию. Настройки внутреннего хранилища резервируются отдельно от SD.

## Что уже проверено и что остаётся

Подтверждены установка через qFlipper, загрузка и управление экраном по RPC, переключение RU/EN, сохранение языка, обновление строк System и Settings, просмотр всех 12 тем на каждом языке, открытие Archive, существующего ИК-файла и стартового экрана внешнего NFC-приложения. После ручного просмотра темы Sub-GHz не показал её повторно после перезагрузки.

Полные испытания радиопередачи, записи и эмуляции меток, GPIO, BadUSB, U2F и всех внешних приложений не выполнены. Первый автоматический показ руководства также ещё не проверен. Некоторые системные экраны и сторонние FAP остаются английскими; в одной русской теме есть неудачный перенос слова.

При проблеме сверяйтесь с [инструкцией по установке и восстановлению](INSTALL_RU.md) и [ограничениями релиза](RELEASE_NOTES_RU.md). Для Issue укажите версию, язык, приложение и последовательность действий; прикладывайте только материалы без личных данных.
